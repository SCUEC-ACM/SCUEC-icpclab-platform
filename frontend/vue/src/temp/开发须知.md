# 四、Docker 架构

项目通过 **Docker Compose** 管理多个服务。

当前系统包含三个核心服务：

- **frontend**：Vue3 前端服务（Nginx 提供静态资源）
- **backend**：Go 后端 API 服务
- **database**：PostgreSQL 数据库

系统架构如下：

```
Browser
   │
   ▼
frontend (Vue + Nginx)
   │
   ▼
backend (Go API)
   │
   ▼
database (PostgreSQL)
```

# 六、环境变量配置

项目运行依赖以下环境变量：

```
DB_USER
DB_PASSWORD
DB_NAME
```

在项目根目录创建 `.env` 文件：

```
DB_USER=postgres
DB_PASSWORD=postgres
DB_NAME=lab_platform
```

说明：

- `DB_USER`：数据库用户名
- `DB_PASSWORD`：数据库密码
- `DB_NAME`：数据库名称

------

# 七、启动项目

在项目根目录运行：

```
docker compose up -d --build
```

参数说明：

| 参数      | 作用         |
| --------- | ------------ |
| `--build` | 构建镜像     |
| `-d`      | 后台运行容器 |

------

# 八、停止项目

停止并删除容器：

```
docker compose down
```

------

# 九、数据库初始化

数据库启动时会自动执行初始化脚本：

```
database/init.sql
```

该脚本用于：

- 创建数据库表结构
- 初始化基础数据

------

# 十、数据持久化

PostgreSQL 数据通过 Docker Volume 进行持久化存储：

```
db_data
```

即使容器删除，数据库数据仍然会保留。

------

# 十一、开发建议

1. 所有敏感配置应写入 `.env` 文件，不应提交至代码仓库。
2. 推荐在 `.gitignore` 中加入：

```
.env
```

1. 新开发者首次运行项目时：

```
1. clone 项目
2. 创建 .env 文件
3. 运行 docker compose up -d --build
```

即可启动完整开发环境。
