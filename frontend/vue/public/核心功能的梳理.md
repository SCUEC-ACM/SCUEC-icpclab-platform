# 网站项目核心功能规划与后端学习路线

## 一、 核心功能梳理 (修正版)

### P0 级：核心内容展示（MVP 最小可行性产品）

*目标：让网站跑起来，完成前后端与数据库的基础闭环。*

- **公告系统（单向展示）：** 站长发布网站最新进展，访客查看。（暂不开放访客发布建议，避免无账号状态下的垃圾信息泛滥）。
- **资源板块（文件下载）：** 展示文档列表，提供点击下载功能。（注意：物理文件通常存放在服务器本地目录或云存储 OSS 中，数据库仅记录文件名称、介绍和下载链接）。
- **基础数据库设计：** 为“公告信息”和“资源信息”建立最基础的数据表。

### P1 级：用户系统与核心交互

*目标：让网站活起来，引入用户状态和互动。*

- **注册与登录系统：** 网站互动的基础，实现 Token 下发与状态保持。
- **建议与论坛板块：** 在有账号体系的支撑下，开放用户发帖、提交建议、回帖互动功能。
- **个人中心：** 用户基础信息记录（修改头像、昵称等），以及个人发布内容的聚合展示。
- **数据收集表功能：** 类似问卷填写，用于收集用户的特定反馈或报名信息。

### P2 级：后台管理与高阶功能

*目标：让网站稳下来，建立秩序和扩展生态。*

- **RBAC 权限系统：** 建立基于角色的权限控制（如区分：超级管理员、版主、普通用户），决定谁能看什么、操作什么。
- **全站信息管理看板 (Dashboard)：** 为管理员提供一个可视化的后台，方便进行删帖、封号、审核资源等全局操作。
- **扩展工具集：** 根据网站发展需求，添加其他实用的附属小工具。

## 二、 后端技术学习路线 (Go + Gin + PostgreSQL)

针对目前的 Vue 3 前端，你需要按以下顺序点亮后端技能树：

### 阶段 1：Go 语言基础（地基）

不要直接上手框架，先掌握 Go 的核心语法和设计哲学。

- **核心语法：** 变量声明、基础数据类型、控制流（`if`, `for`, `switch`）。
- **关键数据结构：** 切片 (`Slice`)、字典 (`Map`)。
- **面向对象替代方案：** 结构体 (`Struct`) —— 这是重中之重，你的数据库表在 Go 代码里就是用结构体来映射的。
- **底层概念：** 基础的指针 (`Pointer`) 概念。
- **Go 的特色：** 基础错误处理机制 (`if err != nil`)。

### 阶段 2：PostgreSQL 与 SQL 基础（数据仓库）

即使后面用代码操作，也必须懂底层的数据库语言。

- **核心 SQL 语句：** 熟练掌握增 (`INSERT`)、删 (`DELETE`)、改 (`UPDATE`)、查 (`SELECT`)。
- **建表语句：** 学会使用 `CREATE TABLE`，了解常用的数据类型（如 `VARCHAR`, `TEXT`, `INT`, `TIMESTAMP`）。
- **必备工具：** 安装 PostgreSQL 数据库环境，并安装一款图形化管理工具（强烈推荐 **DBeaver** 或 **Navicat**），方便直观地查看和修改数据。

### 阶段 3：Go 连接与操作数据库（桥梁）

- **主流方案了解：** 了解 Go 操作数据库的方式（原生 `database/sql` 包）。
- **重点突破（极力推荐）：** 学习 **GORM** 框架。它是 Go 生态中最强大的 ORM 库，可以让你像写普通 Go 代码（操作结构体）一样去操作数据库，大幅降低新手直接写复杂 SQL 的心智负担。

### 阶段 4：Gin 框架开发 API（造房子）

开始编写能够让 Vue 3 发送请求并获取数据的真实接口。

- **路由控制 (Routing)：** 定义 API 路径（例如 `GET /api/notices` 用于获取公告列表）。
- **上下文处理 (`\*gin.Context`)：** 掌握如何接收前端传来的 JSON 参数。
- **数据返回：** 掌握如何将数据库查到的数据，打包成 JSON 格式响应给前端。
- **跨域处理 (CORS)：** 解决前端 Vue (如运行在本地 5173 端口) 请求后端 Gin (如运行在本地 8080 端口) 时必然会遇到的浏览器跨域拦截问题。
